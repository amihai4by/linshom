# ערכת עיתונות · Linshom press kit

Assets and copy for the Google Play listing and any coverage.

| File | Use | Constraint |
|---|---|---|
| `icon-512.png` | Play store icon | 512×512, 32-bit PNG, no transparency |
| `feature-graphic-1024x500.png` | Play feature graphic | 1024×500 |
| `app-name.txt` | Listing title | ≤ 30 characters |
| `short-description.txt` | Listing short description | ≤ 80 characters |
| `full-description.txt` | Listing full description | ≤ 4000 characters |
| `release-notes-he.txt` / `-en.txt` | "What's new" | ≤ 500 characters per language |

All copy is Hebrew-first; the English release notes exist for the `en-US`
listing locale.

**Every claim in this copy is true of the shipped build.** If a feature
changes, change the copy in the same commit — advertising something the app
does not do is a Google Play policy violation, not just a quality issue.

The app icon is the project's own artwork. Screenshots are not in this kit:
Play requires real in-app captures, produced per-device.
